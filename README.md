# Сравнение домов на первом экране

Отдельное превью трёх вариантов. Основной сайт https://kastet36.github.io/ruspom-preview-2/ не изменяется.

Оформление скопировано из первого экрана основного лендинга (2720b47). Переключатель меняет только фоновое изображение и его кадрирование. Параметр `?house=panorama`, `terrace` или `long-terrace` сохраняет выбранный вариант в ссылке.

Изображения подготовлены встроенным imagegen на основе фотографий галереи. Это концепции вечернего света и окружения; их нужно согласовать перед использованием на основном сайте. По прямой просьбе пользователя водяные знаки удалены с трёх экспериментальных фонов. Исходные фотографии сохранены без изменений. Используются assets/panorama-clean.png, assets/terrace-clean.png и assets/long-terrace-clean.png. Промпт удаления: research/watermark-removal-prompt.json. Исходники доступны по ссылке в превью. Промпты: research/image-prompts.json.
