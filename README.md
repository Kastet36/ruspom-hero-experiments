# Сравнение домов на первом экране

Отдельное превью трёх вариантов. Основной сайт https://kastet36.github.io/ruspom-preview-2/ не изменяется.

Оформление скопировано из первого экрана основного лендинга (2720b47). Переключатель меняет только фоновое изображение и его кадрирование. Параметр `?house=panorama`, `terrace` или `long-terrace` сохраняет выбранный вариант в ссылке.

Изображения подготовлены встроенным imagegen на основе фотографий галереи. Это концепции вечернего света и окружения; их нужно согласовать перед использованием на основном сайте. Водяные знаки сохранены. Исходники доступны по ссылке в превью. Промпты: research/image-prompts.json.
